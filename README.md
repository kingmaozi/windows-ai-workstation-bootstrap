# Windows AI Workstation Bootstrap

**公开、MIT许可的Windows新机初始化任务包。** 面向可复制给ZCode/其他编码代理执行的安全配置方案，不是已经实现的“一键部署器”。

## 直接开始

打开 **[START-HERE.md](START-HERE.md)**，将全文交给目标Windows上的ZCode。该文件可独立使用，不需要访问任何私有仓库。

默认目标：**Windows 11 Pro for Workstations x64、Z790 APEX、i9-13900KS、RTX4090 24GB、32GB（16GB×2）DDR5-8000 CL36**。其他机器先改配置事实，不照抄盘符/BIOS/驱动版本。这里沿用已选工作站版，不声称该edition会提高GPU推理性能。

- Windows开源代理客户端：**Clash Verge Rev**为默认，**v2rayN**为条件备选。
- 安装底座：微软**WinGet**精确小清单，只补缺失软件。
- 系统设置：有依据、保存旧值、可回退；不跑“一键精简”预设。
- 本地生成：原生**ComfyUI**、单GPU/batch1、确定性媒体合成、人工待审。
- 用户数据：不主动删除/清理/卸载/格式化，不覆盖既有工程或模型。

## 必须先知道

**客户端不含上游服务。** 用户需在目标机本地导入合法订阅或自建服务器配置，不把URL/token/密码发到公开issue或聊天。没有凭据就准确标记待配置，不能用未知免费节点兜底。

**“不删文件”是执行约束，不是零风险保证。** 软件安装器和系统更新会写自身文件；先备份关键数据，设置变更记录原值。系统还原点不等于文件备份，抽样hash也不能证明整盘绝对不变。

**不能把研究方案冒充已部署。** 本项目尚未在目标Windows验证安装、实际网络、CUDA推理、重启恢复或24/72小时长稳。接手代理须逐项留证，待实现的worker/审核/监控不假称已有。

**开源范围：** 本仓库原创文档与配置采用[MIT许可证](LICENSE)。Windows、NVIDIA驱动、ZCode、WebView2等外部依赖各有许可证，未被重新许可。外部项目代码、安装包、模型权重、订阅和系统密钥不随仓库分发。

## 权限底线

不禁用Defender、防火墙、SmartScreen或更新，不破解激活，不改BIOS/XMP/电压，不自动重启/付款/接受模型商业许可，不公开8188/3389，不自动登录或发布视频。敏感动作在目标机获得对应授权；必要可逆工作按任务书推进，不为每步重复询问。

代理只用于合法软件联网，不改变模型地域许可或任何平台账号准入要求。MiniMax H3本地权重协议包含输出的地域使用/分发/展示限制；美国商业输出授权未明确前保持隔离，详见视频规格。
